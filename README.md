Entry for the make.fun competition **Make the AI Judge Laugh: Office Jokes**.

`main.py` (Python 3.13, standard library only) writes one one-line joke about
office life to `/output/entry.txt`. The joke is under 200 characters, a single
line, and nothing else.

## The joke

> My performance review said 'be more visible' — so now I attend meetings on camera, muted, doing nothing.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
